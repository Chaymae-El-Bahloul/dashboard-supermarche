Sales Dashboard - Analyse des Ventes avec Streamlit

** Présentation

Ce projet consiste en la conception et le développement d’un tableau de bord interactif permettant d’analyser les données de ventes d’un supermarché.

L’objectif principal est de fournir un outil visuel simple et efficace pour explorer les performances commerciales, identifier les tendances et faciliter la prise de décision basée sur les données.

⸻

** Objectifs  :

	•	Analyser les ventes de manière interactive
	•	Identifier les produits les plus performants
	•	Comprendre le comportement des clients
	•	Suivre l’évolution des ventes dans le temps
	•	Visualiser les données à travers des graphiques dynamiques

⸻

** Fonctionnalités principales :

	•	Filtres interactifs (ville, produit, paiement, genre, note, mois)
	•	Indicateurs clés de performance (KPI) :
	  •	 Ventes totales
	  •	 Nombre de transactions
	  •	 Note moyenne
	  •	 Vente moyenne
	•	Visualisations :
	 •	Diagramme en barres
	 •	Diagramme circulaire
	 •	Courbe temporelle
	 •	Histogramme
	 •	Boxplot
	 •	Scatter plot
	 •	Heatmap (corrélation)
	 •	Sunburst (analyse hiérarchique)
	 •	Gauge (satisfaction client)

⸻

** Technologies utilisées:

	•	Python
	•	Streamlit
	•	Pandas
	•	Plotly
