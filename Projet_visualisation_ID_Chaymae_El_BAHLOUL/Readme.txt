Tableau de Bord des Ventes — Supermarché Myanmar (T1 2019)
***Description du projet

Ce projet est une application de Business Intelligence interactive développée avec Streamlit.
Elle permet d’explorer et d’analyser les données de ventes d’un supermarché sur le premier trimestre 2019.

Le dashboard transforme des données brutes en insights visuels exploitables, facilitant la prise de décision.

*** Objectifs
Visualiser les performances commerciales
Identifier les produits et branches les plus rentables
Comprendre le comportement des clients
Analyser les tendances temporelles
Fournir une interface interactive et intuitive
** Contenu du dashboard
  1. Indicateurs clés (KPI)

Le dashboard affiche des indicateurs essentiels :

Chiffre d’affaires total
Revenu brut
Coût des marchandises
Taxes collectées
Branche la plus performante

Chaque KPI inclut :

Une évolution par rapport à la période précédente
Une mini-tendance (sparkline)
Une barre de progression
Une interaction (clic pour filtrer les données)
  2. Système de filtres

L’utilisateur peut affiner l’analyse grâce à plusieurs filtres :

Période (dates)
Catégorie de produit
Branche
Ville
Mode de paiement
Type de client
Genre

Les filtres sont dynamiques et impactent toutes les visualisations.

Évolution quotidienne des ventes
Moyenne mobile et cumul
Analyse par heure et jour
Identification des pics d’activité
** Données & statistiques
Statistiques descriptives
Distribution des variables
Matrice de corrélation

** Insights générés

Le dashboard permet d’identifier :

Le produit le plus rentable
La branche dominante
Le mode de paiement le plus utilisé
Les périodes de forte activité
Les segments clients les plus performants
** Technologies utilisées
Streamlit : création de l’interface interactive
Pandas : manipulation et transformation des données
Plotly : création de graphiques dynamiques
NumPy : calculs statistiques
** Données

Le projet repose sur un fichier contenant :

1000 transactions
Informations sur les ventes (produits, prix, quantités)
Données clients (type, genre)
Informations temporelles (date, heure)
Données financières (taxe, revenu, coût)
** Design et expérience utilisateur

Le dashboard a été conçu avec :

Un mode sombre / clair
Des animations interactives (hover, transitions)
Une navigation par onglets
Une mise en page professionnelle inspirée des outils BI
** Points forts
Interface moderne et intuitive
Visualisations interactives
KPI cliquables (filtrage rapide)
